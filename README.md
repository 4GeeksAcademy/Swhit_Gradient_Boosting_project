# Boosting Algorithms - Diabetes Prediction

## Project Overview
This project applies boosting algorithms to predict diabetes outcomes based on health-related features such as glucose levels, BMI, age, and more. The goal is to improve predictive performance compared to baseline models.

## Dataset
- Source: Diabetes dataset
- Features include:
  - Pregnancies
  - Glucose
  - Blood Pressure
  - BMI
  - Age
  - Insulin
  - Diabetes Pedigree Function

## Methods
- Data cleaning and preprocessing
- Train-test split
- Model training using:
  - Gradient Boosting Classifier
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - Confusion matrix

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## Results
The boosting model improves prediction performance by focusing on misclassified samples and iteratively refining the model.
